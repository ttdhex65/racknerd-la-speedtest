**自测步骤**：

2. 输入 `ping 107.174.51.158` 看延迟
3. 连续 ping 的话加 `-t`（Windows）或 `-c 30`（Linux/Mac），观察丢包情况

建议在白天和晚高峰各测一次，对比差距。晚高峰延迟比白天高个 20-30ms 很正常，如果高出 50ms 以上且丢包，说明你所在地区到洛杉矶这段线路晚间拥堵比较严重。
